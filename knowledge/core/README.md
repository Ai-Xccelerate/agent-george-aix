## Conventions

- **Partner** = the MSP / CSP Onyx contracts with. **Customer** = the partner's end customer. Use these consistently.
- **Program manager / Coach** are the same role; pick one in a given document and stay with it.
- **Win → Support → Grow** is the platform arc. **Transition Hub** is the lead product. **Sales Hub is parked.**
- Customer-facing artifacts default to the partner's brand and the partner's voice, not Onyx's.
